# WhatsApp CRM for Windows

This repository contains Windows x64 installers and public update manifests. Application source is maintained separately.

## Install

Open the latest stable release and download the WhatsApp-CRM-Setup installer. The installer bundles the application runtime; recipients do not need Python, Node.js, Docker, or a separate Chrome installation.

This initial release is unsigned. Windows may show an unknown-publisher warning. Do not disable Windows security protections.

Set up your own WhatsApp account and AI credentials in the application. Developer accounts, customer databases, and credentials are not bundled. Updates retain local user data.

In-app updates require an explicit download and installation confirmation. The first release establishes the update channel; an actual version-to-version upgrade still needs end-to-end validation.
